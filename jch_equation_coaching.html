JCH 논문 수식 코칭 자료 (Eq.1~Eq.7)

요청하신 대로 더 자세한 수식 코칭을 위해, 각 수식마다 개념 + 계산 단계 + 해석 + 시각화를 같이 배치했습니다.

학습 흐름 SNR → RMSE → SAM → R950/R1000 → Continuum/CR/BD1900 → PCA

0) 신뢰도 점검: SNR

SNR(λ)= μ(λ) / σ(λ)
  • μ(λ): 해당 파장의 평균 신호(목소리), σ(λ): 표준편차(소음).
  • SNR이 높은 파장일수록 후속 해석(RMSE/SAM/BD/PCA) 신뢰도가 높습니다.

Eq.(1) RMSE — 변화량 크기

RMSE = √[(1/N) Σ (Rt(λi)-R0(λi))²]

코칭 포인트

  • 모든 파장을 한 번에 합쳐 "초기 상태와의 거리"를 계산합니다.
  • 값이 작으면 안정적, 크면 시간 변화가 큽니다.
  • 주의: 밝기 변화와 형태 변화를 분리하지 못함 → SAM과 같이 봐야 함.

Eq.(2) SAM — 형태 유사도(각도)

SAM = cos⁻¹[(Rt · R0) / (|Rt||R0|)]
  • 스펙트럼을 벡터(화살표)로 보고 각도를 구합니다.
  • 밝기가 2배가 되어도 방향이 같으면 SAM은 작게 유지됩니다.
해석: SAM≈0°(형태 유지), SAM↑(형태 변화 증가)

Eq.(3) R950/R1000 — 밴드비 지표

R950/R1000 = mean(R945–955)/mean(R995–1005)
  • 950nm 특징 구간(분자)을 1000nm 기준 구간(분모)으로 나눠 정규화합니다.
  • 1.0 근처면 평탄, 값이 클수록 950nm 피처가 뚜렷합니다.

Eq.(4)~(6) Continuum → CR → BD1900

Rc(λ)=Rl+(Rr-Rl)×(λ-λl)/(λr-λl)
Rcr(λ)=R(λ)/Rc(λ)
BD = 1 - Rcr(λc)
  1. 어깨를 잇는 직선(continuum) 구성
  2. 실제 스펙트럼을 continuum로 나눠 정규화
  3. 1900nm 중심에서 깊이(BD) 계산

Eq.(7) PCA Score — 분산 구조 요약

tk = Xc × pk
  • 수백 파장을 PC1/PC2 축으로 압축해서 군집 분리 확인.
  • 가까운 점=유사 스펙트럼, 멀수록 이질.
