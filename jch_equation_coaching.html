JCH 논문 수식 코칭 자료 (디테일 강화판)

각 수식을 해부해서 설명합니다: 기호 의미 → 왜 이 연산이 필요한지 → 왜 이 파장대를 고르는지 → 결과 해석.

학습 순서 SNR → RMSE(Eq.1) → SAM(Eq.2) → R950/R1000(Eq.3) → Continuum/CR/BD(Eq.4~6) → PCA(Eq.7)

0) 사전 체크: SNR

SNR(λ)= μ(λ) / σ(λ)

해부

  • μ(λ): 해당 파장 평균값(신호 크기)
  • σ(λ): 해당 파장 흔들림(잡음 크기)

왜 먼저 보나?

  • SNR 낮은 파장은 식이 정교해도 결론이 불안정합니다.
  • 즉, SNR은 해석의 품질 필터입니다.

Eq.(1) RMSE — 전체 변화량

RMSE = √[(1/N) Σ (Rt(λi)-R0(λi))²]

수식 해부

구성요소의미왜 필요한가
Rt - R0파장별 변화량기준 대비 변화의 방향(+/-)과 크기를 얻음
제곱(차이)²음/양 상쇄 방지, 큰 변화에 가중치 부여
평균(1/N)파장 수로 정규화밴드 수가 달라도 비교 가능
제곱근원단위 복귀왜 루트? 제곱으로 커진 단위를 반사율 단위로 되돌려 직관적 해석
핵심: RMSE는 “얼마나 멀어졌는지(크기)”를 말하고, “어떻게 변했는지(형태)”는 SAM이 담당.

Eq.(2) SAM — 형태(Shape) 변화

SAM = cos⁻¹[(Rt · R0) / (|Rt||R0|)]

수식 해부

  • 내적/노름 정규화를 통해 벡터 길이(밝기) 영향 제거, 방향(형태)만 비교.
  • 왜 각도? Rt = k·R0 (k>0)면 SAM=0°: 밝기 배율이 달라도 형태가 같음을 보장.
즉, 조명/표면 거칠기 변화가 있어도 “흡수대 모양 자체 변화”에 집중할 수 있습니다.

Eq.(3) R950/R1000 — 왜 950/1000인가?

R950/R1000 = mean(R945–955) / mean(R995–1005)

수식 해부

선택이유
945–955nm (분자)논문에서 분리력이 관찰되는 950nm 특징 피처 구간
995–1005nm (분모)인접 기준 평탄대(로컬 기준선)로 조명·알베도 공통 변화 보정
단일값 대신 평균센서 노이즈/밴드 위치 미세 오차 완화
왜 이 파장대? “특징이 있는 곳 / 바로 옆 기준구간”의 비율로 물질 고유 피처만 남기는 설계입니다.

Eq.(4)~Eq.(6) Continuum / CR / BD

Rc(λ)=Rl+(Rr-Rl)×(λ-λl)/(λr-λl)
Rcr(λ)=R(λ)/Rc(λ)
BD(λc)=1-Rcr(λc)

수식 해부

  1. Continuum(Eq.4): 흡수대가 없었다면 따랐을 배경 직선(선형 보간)
  2. CR(Eq.5): R/Rc로 배경 기울기 제거(어깨≈1.0 정렬)
  3. BD(Eq.6): 중심 파장 깊이만 수치화 (1-Rcr)
왜 1900nm? 수분(H₂O)/OH 관련 흡수에 민감한 대역으로, 모르타르 수분 거동 추적에 핵심입니다.

Eq.(7) PCA Score — 고차원 요약

tk = Xc × pk

수식 해부

  • Xc: 평균 중심화 데이터(시편×파장)
  • pk: k번째 로딩(어떤 파장이 축을 만들었는가)
  • tk: 시편의 k축 점수(어디에 위치하는가)
왜 PCA? 수백 파장 정보를 2~3축으로 압축해 군집 분리, 시간 궤적, 처리군 이질성을 직관적으로 확인하기 위함.
