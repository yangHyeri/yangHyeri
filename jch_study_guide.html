JCH 논문 수식 학습자료 (Eq.1~Eq.7)

이 문서는 초분광 보존 분석에서 사용한 7개 수식을 논문 해석 중심으로 공부할 수 있게 정리한 HTML 학습자료입니다.

학습 순서: SNR → RMSE → SAM → R950/R1000 → Continuum → CR → BD1900 → PCA

0) 데이터 품질 확인: SNR

SNR(λ) = μ(λ) / σ(λ)
  • μ(λ): 해당 파장 평균 신호, σ(λ): 잡음 변동
  • SNR이 낮은 구간은 해석을 보수적으로 해야 합니다.

Eq.(1) RMSE — 전체 변화량(크기)

RMSE = √[(1/N) Σ (Rt(λi) - R0(λi))²]
  • 기준 시점 대비 얼마나 멀어졌는지(절대 변화량)를 한 숫자로 표현.
  • 값이 작을수록 장기 안정성이 높습니다.

Eq.(2) SAM — 형태 변화(모양)

SAM = cos⁻¹[(Rt · R0) / (|Rt||R0|)]
  • 밝기 스케일보다 스펙트럼 형태 변화에 민감합니다.
  • SAM ≈ 0°이면 형태가 거의 동일합니다.

Eq.(3) R950/R1000 — 950nm 특징 피처

R950/R1000 = mean(R945–955) / mean(R995–1005)
  • 조명/알베도 영향을 줄이기 위한 밴드비 지표.
  • 1에 가까우면 평탄, 값이 커지면 950nm 피처 강화.

Eq.(4) Continuum — 기준선 정의

Rc(λ) = Rl + (Rr - Rl) × (λ - λl) / (λr - λl)
  • 흡수대 양쪽 어깨를 직선으로 연결해 기준선을 만듭니다.

Eq.(5) Continuum Removed Reflectance

Rcr(λ) = R(λ) / Rc(λ)
  • 기준선 대비 흡수대 형태를 정규화해 비교하기 쉽게 만듭니다.

Eq.(6) BD1900 — 흡수대 깊이

BD = 1 - Rcr(λc) = 1 - R(λc)/Rc(λc)
  • 1900nm 수분/OH 관련 흡수 강도를 정량화합니다.
  • 값이 클수록 흡수대가 깊습니다.

Eq.(7) PCA Score — 전체 스펙트럼 구조 요약

tk = Xc × pk
  • 수백 파장을 2~3축으로 압축해 처리군 간 분포를 비교합니다.
  • 점이 가까우면 유사, 멀면 분광학적 차이가 큽니다.

빠른 해석표 (논문용)

상황의미
RMSE↑ + SAM↓밝기/수준은 변했지만 형태는 유지
RMSE↓ + SAM↑전체 수준은 비슷하지만 형태 변화 존재
R950/R1000↑950nm 특이 피처 강화
BD1900↑1900nm 수분/OH 흡수 심화
PCA 분리↑처리군 간 분광 차이 확대
